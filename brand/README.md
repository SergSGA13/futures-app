# Фирменный стиль FUTURES PREDICTION

Ассеты из brand-kit пульта исполнителя. Подключены в `styles.css`
(блок «ФИРМЕННЫЙ СТИЛЬ FUTURES PREDICTION» в конце файла) и `index.html`.

| Файл | Где используется |
|---|---|
| `bg-wide-3440x1440.jpg` | фон-сцена на широких экранах |
| `bg-portrait-1170x2532.jpg` | фон-сцена на телефоне и вертикальных окнах (`max-aspect-ratio: 1/1`) |
| `orbitron.woff2` | надпись проекта и малые заголовки, только латиница |

Файлы скопированы из кита без изменений. Если кит обновится — заменить
файлы с теми же именами, правки в коде не нужны.

## Шрифт

Orbitron, автор Matt McInerney. Лицензия SIL Open Font License 1.1:
https://openfontlicense.org — шрифт можно свободно встраивать и
распространять вместе с приложением, продавать сам по себе нельзя.
В Orbitron нет кириллицы: русские и украинские буквы браузер берёт из
следующего в списке системного шрифта.
